# QuickAssist - Vehicle Breakdown Solution

A full-stack application providing real-time assistance for vehicle breakdowns.

---

## Project Structure

- `/backend` — Backend API server  
- `/client` — React frontend app  

---

## Setup Instructions

### Backend

```bash
cd backend
npm install
# Create a .env file with your DB connection string and other env variables
npm start

```

### client

```bash
cd client
npm install
# Create a .env file with your REACT_APP_OPENAI_API_KEY
npm run dev

```

### Usage

```bash
start backend and client in two powershells
Visit http://localhost:5173/ after starting both servers.
```
